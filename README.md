# 店舗造作作成ソフト（ダーツバー向け店舗プランナー）

ブラウザだけで動く単一HTMLの店舗レイアウト・内装プランニングツール。
ファイルをダブルクリックしてブラウザで開くだけで使えます（インストール不要）。

## ファイル

| ファイル | 内容 |
|---|---|
| `restaurant-planner-v2.html` | **本体（最新版）**。ダーツバー専用 |
| `restaurant-interior-advisor.html` | 初期プロトタイプ（多業態対応の自動生成型）。参考用 |

## v2 の主な機能

- **図面PDF読み込み**：CAD出力のPDFを下絵に表示。2点クリックで縮尺合わせ→売場範囲をドラッグ指定
- **壁・柱の自動抽出（ベータ）**：PDFのベクター線から躯体壁・柱を検出してスケルトン化
- **自由レイアウト編集**：ミニチュア付きパレットから18種の什器を配置。ドラッグ移動・回転・伸縮・複製・Undo
  - ダーツレーン（スローライン2,440mm表示）、6名/4名/2名卓、ハイ卓500×600、カウンター、造作壁、入口/小ドア、梁・柱 ほか
- **仕上げ選択**：什器ごとに木部6色×張地6色×脚（スチール/木）を変更、2D/3Dに即反映
- **3Dパース**：ドラッグで視点回転。俯瞰/入口/カウンター前プリセット、テイスト6種切替
- **診断**：席数・1席あたり面積・厨房比率・重なり検出・防火管理者要否など
- **自動保存＆物件ライブラリ**：編集は都度ブラウザ(localStorage)に保存。過去物件の一覧から復元。JSON書出/読込も可

## 技術メモ

- 依存ライブラリは pdf.js（CDN）のみ。PDF読み込み時のみネット接続が必要
- 保存データはブラウザの localStorage（同じPC・同じブラウザで有効）
- 図面の実寸換算は手動キャリブレーション方式（通り芯寸法の利用を推奨）
